# US100 频道选择流程（2026-09-18）

## 结论

US100（2.24.0.124）客户端用 **3 模式启动参数**可以走完整频道流程：

```
3?127.0.0.1?7001?probe?00000000000000000000000000000000?0?0?30?0?0?0
```

实测（runtime/channel3/events.jsonl，客户端 300 秒稳定）：

1. 客户端连接 127.0.0.1:7001，成功取回频道目录
   （channel_refresh_finished success=true，耗时 1ms/5ms 各一次）。
2. 客户端展示频道选择界面（截图 us100_ch015s..ch264s.png 覆盖全过程）。
3. 客户端按目录中的游戏地址（127.0.0.2:动态端口）连接网关：
   precheck(1554) → login(1) → 标准启动命令 → GET_USERINFO(8)。
4. 频道入场时客户端发送 **id=2**（45 字节：模式 0x05、本机 IP×2、
   u16 端口、u16 2、u16 0、u16 长度 12、12 字节频道密钥
   `30c599b465a4` + NUL）。这是频道进入后的本机地址上报，**无需应答**，
   客户端发完即继续（第二次会话中 id=2 后紧跟 id=8 取名单）。
5. 名单（V224 布局）→ 848/433/637 → 217，全流程无崩溃。

## 两种启动模式

| 模式 | 参数 | 行为 |
|---|---|---|
| 13 | `13?<host>?<port>?probe?...` | 直连游戏服，跳过频道选择界面 |
| 3 | `3?127.0.0.1?7001?probe?...` | 目录 → 频道选择界面 → 自动/手动进入频道 |
