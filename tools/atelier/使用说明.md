# 地下城与勇士 · 智慧的引导 (Lv.100 神话纪元)

双击工程根目录的 `100US登录器.exe`，在「登录与启动」点「立即进入 100 级世界」。默认是随附代码改造的 PySide6 暗金界面。账号、线路和路径显示当前实际使用的本地配置，不会递归启动登录器。若网关离线会先启动网关；若游戏已在运行，不会再开第二个。关掉登录器不结束游戏或网关。运行日志在 `runtime/launcher.log`。

## GM

- **物品可视化添加**：按 ID、中英文名称、资源路径、稀有度、职业或部位筛选。选角色和数量后添加物品，再确认提交。每笔在入队时绑定角色；发放失败的原因可查网关回执。网关显示「支持在线到账」时，在线角色在存档入账后收到背包刷新，不必退出；离线角色在下次登录时读取。已入包回执证明存档已写入，不代表客户端画面已确认。只有旧网关才需等待所有客户端退出。不要重复提交。
- **实时 PVF 与 NPK 自动选择**：首页「实时资源源」默认自动追踪当前客户端的 `Script.pvf`（支持外层加密 PVF 自动解包与直接读取 PVF 内置词条，不再固守旧版 `Script.inner.pvf`）及 `ImagePacks2` 目录。支持一键手动选择任意 PVF 文件或 NPK 目录，后台每 3 秒自动检测文件大小与修改时间变动，自动增量同步并热重载物品库、图标和试衣间预览，无需重启登录器。
- **时装试衣间**：可视化卡片网格 + 左侧 11 部位交互式人偶槽位（含「武器装扮」「光环」及帽子/头发/脸部/胸部/上衣/腰部/下装/鞋子/肤色 9 大常规部位）。支持点击部位槽位快速筛选、右键或点 `×` 单独卸下、成套礼包整套试穿、随机搭配、缩放与舞台背景切换、图层显隐开关、IMG v6 多调色板变色以及光环实时动画与加色发光混合。不会更改游戏角色。
- **深渊掉落**：指定房间、装备和百分比，保存在 `runtime/launcher-gm/abyss.json`。这是本地额外掉落，不是客户端原生深渊模式开关。0% 关闭；100% 在选中房间每个由网关确认死亡的战斗怪额外掉一件所选装备，不替换普通掉落。新规则在新副本的第一次掉落时读取。同一次死亡不会重复发放。游戏已经开始掉落时请重新进副本。
- **全局预设**：保留原稿的倍率、神话/史诗权重与池模式，可显式导出到 `runtime/launcher-gm/global_abyss_config.json`。这个 JSON 不是当前网关的掉落规则；打开界面不会改写预设或掉率。

## 物品图标

物品卡片从当前客户端的 `ImagePacks2` 读取背包图标，使用物品脚本的 `[icon]` 图集路径和从 0 开始的帧号。悬停在图上可查看引用；共用同一帧的物品会显示相同图片。缺包、缺帧或缺少引用时显示问号及原因，不以相邻物品代替。更换 NPK 后重新打开物品页或切换分页，即可重新读取变化的包。

## Mod 工坊

**游戏字体**：完全退出 DFO 后，在「Mod 工坊 → 游戏字体」选本机字体或浏览 TTF/TTC，TTC 可选择具体字面，例如 SimSun（宋体）或 NSimSun（新宋体）。点击「应用字体」，等待校验完成后再启动游戏。此功能将所选的静态 TrueType 字面制作为客户端要求的 Tahoma、Calibri 两个入口，保留源字体，不安装到 Windows。点击「还原原版字体」可恢复与原包指纹一致的两个文件。字体被其他程序改动时不会静默覆盖。

**90JP 规范 PVF + NPK 合并 Mod**：在「Mod 工坊」导入或将 Mod 压缩包放入客户端 `MOD/` 目录（支持 90JP 两级 `version.json` 合集/子模组 ZIP，包含 `PVF/` 脚本与 `NPK/ImagePacks2`、`NPK/SoundPacks` 资源，也兼容普通 PVF/NPK ZIP 及单文件 `.npk`）。勾选启用的子模组并通过「上移 / 下移」调整优先级（排序靠前者胜出），点击「保存并合并到 PVF」后，登录器先备份原版 `Script.pvf` 基线，按优先级自动合并普通文件、按数字 ID 合并 `.lst` 索引、按词条键合并 `.str` 表、编译脚本、回读校验并重封装为客户端 `Script.pvf`，同时部署 NPK 资源并触发实时索引重载。点击「还原原版 PVF 与 NPK」可按 SHA-256 完整恢复原版文件。游戏运行时禁止合并或还原。

## 维护

默认入口为 `tools/atelier/bootstrap.pyw`。随附稿的布局、卡片与样式在 `epic_ui.py`，网关、预览和 Mod 适配在 `epic.py`。本机使用 Windows Python 3.14、Pillow、psutil 和工程专用的 Qt 运行库。若迁移到新电脑，可在工程根目录运行 `python -m pip install --only-binary=:all: --target runtime/atelier-qt PySide6-Essentials==6.12.0` 恢复 Qt 依赖。原 Tk 版仍可单独运行 `pythonw tools/atelier/app.py`。一次只打开一个版本。

物品目录来自当前 100US PVF 的完整 equipment.lst 与 stackable.lst，不由掉落池决定。中文显示名来自本地化候选表，英文名来自 US 表，未解析时显示脚本文件名。只有普通背包可接受的模板才有发放按钮，其他物品仍可浏览。新增可发放模板不会自动加入普通掉落池。重建：先在 server-us100 使用工程 Go 运行 `go run ./scripts/atelierlibrary`，再在工程根目录运行 `python tools/atelier/build_library.py`。它会发布新一代 SQLite 目录和 GM 数据，重开登录器即可浏览；网关要在无人在线时重启才加载新一代数据。

全量目录直接读取源脚本的图标引用。旧版基线目录仍使用 `tools/atelier/equipment_icons.json`；`check_item_icons.py` 只审计这部分，不代表整个 PVF 的图标覆盖率。在工程根目录运行 `python -m unittest discover -s tools/atelier -p "test_*.py" -v` 可复测试衣、分页、发放和原有功能。
