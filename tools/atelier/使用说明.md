# 地下城与勇士 · 智慧的引导 (Lv.100 神话纪元)

双击工程根目录的 `100US登录器.exe` 打开暗金主题 PySide6 桌面登录器（入口为 `tools/atelier/bootstrap.pyw`）。首次使用需先在「登录与启动」主页创建账号与密码以生成本地数据库 `server-us100/runtime/us100.db`，验证登录后点击「立即进入 100 级世界」。若网关离线会自动拉起网关；若游戏已在运行，不会重复启动第二个窗口。关闭登录器不会结束运行中的游戏或网关。运行日志位于 `runtime/launcher.log`。

## 账号、数据库与服务端控制（主页）

- **账号创建与密码登录**：输入 3~32 位账号及 4~64 位密码（使用 PBKDF2-SHA256 加密存储）后点击「创建账号」即可自动初始化 `us100.db` 并登录；已有账号可从下拉框快速选取并输入密码点击「登录账号」。
- **删除数据库（忘记密码重置）**：主页账号栏提供红色「删除数据库」按钮（存在 `us100.db` 时启用，未登录状态亦可点击）。二次确认后会自动停止运行中的本地服务端、删除 `us100.db` 及关联临时文件、清理残留待发 GM 队列并重置登录状态，随后可直接输入新账号和密码重新生成全新数据库。游戏客户端运行时禁止删除。
- **旧账号存档迁移**：`tools/atelier/core.py` 提供 `migrate_account_data(src, dst, backup=True)`，可将旧开发账号的角色、点券、积分、契约、材料与活动进度一键迁移到新的带密码账号。
- **服务端启停控制条**：主页支持一键「启动服务端」「重启服务端」「关闭服务端」，并实时显示网关地址、登录账号、PID 与在线 GM 能力状态。

## 核心功能模块

- **物品可视化添加**：按 ID、中英文名称、资源路径、稀有度、职业或部位筛选。选角色和数量后加入队列再确认提交。每笔在入队时绑定角色；发放结果可在「查询网关回执」核对。在线角色入账后会收到背包刷新，无需退出重登。
- **全局掉落设置**：按普通/冒险/勇士/王者/噩梦 5 档难度配置基础掉率倍率、装备掉率、件数与稀有度权重，并支持普通深渊与 100 级深渊（史诗/神话权重、指定房间或自定义装备池），配置保存至 `runtime/launcher-gm/global_drop.json`。旧版单房间额外掉落保存在 `runtime/launcher-gm/abyss.json`。
- **时装试衣间**：可视化卡片网格 + 左侧 11 部位交互式人偶槽位（含武器装扮、光环及 9 大常规部位）。支持点击槽位筛选、成套礼包整套试穿、随机搭配、缩放与舞台背景切换、图层显隐、IMG v6 多调色板变色以及光环实时动画混合，并支持一键将当前搭配发放给角色。
- **角色属性管理**：支持查看与调整角色等级、经验、SP/TP、转职、点券/金币、背包物品与任务状态，通过在线队列实时生效。
- **活动中心**：控制服务端经验/掉率/金币/翻牌倍率活动、深渊派对、周末双倍/燃烧疲劳、每日与每周挑战、积分（Mileage）返利与兑换以及契约加成，保存至 `runtime/launcher-gm/events.json`。
- **实时 PVF 与 NPK 自动选择**：首页「实时资源源」默认自动追踪客户端 `Script.pvf`（支持外层加密 PVF 自动解包与内置词条读取）及 `ImagePacks2` 目录，支持手动切换并在后台每 3 秒自动检测变动热重载，无需重启登录器。

## 物品图标

物品卡片从当前客户端的 `ImagePacks2` 读取背包图标，使用物品脚本的 `[icon]` 图集路径和从 0 开始的帧号。悬停在图上可查看引用；共用同一帧的物品会显示相同图片。缺包、缺帧或缺少引用时显示问号及原因，不以相邻物品代替。更换 NPK 后重新打开物品页或切换分页，即可重新读取变化的包。

## Mod 工坊

**游戏字体**：完全退出 DFO 后，在「Mod 工坊 → 游戏字体」选本机字体或浏览 TTF/TTC（TTC 可选具体字面，如 SimSun / NSimSun）。点击「应用字体」，等待校验完成后再启动游戏。点击「还原原版字体」可恢复与原包指纹一致的字体文件。

**90JP 规范 PVF + NPK 合并 Mod**：支持导入或扫描客户端 `MOD/` 目录中的 90JP 合集/子模组 ZIP、普通 PVF/NPK ZIP 及单文件 `.npk`。勾选启用并调整优先级后点击「保存并合并到 PVF」，登录器会自动备份原版 `Script.pvf`、按优先级合并脚本/`.lst`/`.str`（保留 UTF-16LE 编码与 NUL 终止符）、编译校验并部署 NPK，同时触发目录热重载。点击「还原原版 PVF 与 NPK」可按 SHA-256 完整恢复原版。游戏运行时禁止合并或还原。

## 维护与测试

- 默认入口为 `tools/atelier/bootstrap.pyw`；布局与样式在 `epic_ui.py`，网关与页面调度在 `epic.py`，核心业务与账号/数据库管理在 `core.py`。
- 若迁移到新电脑，可在工程根目录运行 `python -m pip install --only-binary=:all: --target runtime/atelier-qt PySide6-Essentials==6.12.0` 恢复 Qt 运行库。
- 重建全量物品与时装目录：先在 `server-us100` 使用工程 Go 运行 `..\tools\go\bin\go.exe run ./scripts/atelierlibrary`，再在工程根目录运行 `python tools/atelier/build_library.py`。
- 运行测试：
  ```bash
  python -m unittest tools/atelier/test_account_auth.py tools/atelier/test_epic.py tools/atelier/test_fitting_room.py -v
  ```
